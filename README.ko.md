# Cupcake 라이선스

이 저장소는 Ruyari Cupcake가 배포하는 소프트웨어에 붙일 라이선스와 짧은 고지문의
공식 원본입니다. 법적 해석은 영문 라이선스가 우선합니다.

현재 제공하는 `Cupcake Restricted Use License 1.0`은 공식 배포본을 수정하지 않고
통상적으로 사용하는 것은 허용하지만, 다음 행위는 허용하지 않습니다.

- 무단 수정, 역공학, 디컴파일, 파생물 제작
- 비공식 재배포, 미러링, 판매 또는 재라이선스
- 코드나 번들을 AI/LLM에 넣어 분석·설명·디버깅·수정·변환하게 하는 행위
- 학습, 파인튜닝, RAG, 임베딩, 데이터셋, 평가용 수집
- 봇이나 스크래퍼를 통한 자동 수집

플러그인이 본래 기능을 수행하면서 사용자의 대화 내용을 AI API에 보내는 것은
금지 대상이 아닙니다. 금지되는 것은 플러그인 코드·번들·자산 자체를 AI에게 분석이나
학습 재료로 제공하는 행위입니다.

각 파일이나 릴리스에 이 라이선스의 이름과 버전이 명시되어야 실제 적용 대상으로
봅니다. 예전에 MIT 등으로 공개된 버전의 권한을 소급해서 없앨 수는 없습니다.

GitHub 공개 저장소는 GitHub 약관에 따라 누구나 열람하고 포크할 수 있고, GitHub가
업로더에게서 별도로 받는 플랫폼·AI 관련 권리도 이 라이선스로 없앨 수 없습니다.
그 부분까지 원치 않는 소스는 비공개로 유지해야 합니다.

이 문서는 이해를 돕는 요약이며 법률 자문이 아닙니다. 충돌할 경우
[영문 라이선스](licenses/CUPCAKE-RESTRICTED-1.0.md)가 우선합니다.
